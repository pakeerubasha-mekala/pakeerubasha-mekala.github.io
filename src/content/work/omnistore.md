## Context

My first DevOps role. I supported global development teams on the OmniStore platform, covering the delivery pipeline, container platform and production operations.

## What I did

**CI/CD.** Led the CI/CD implementation using Jenkins and shell scripting to automate pipelines, and set up artifact repositories and quality testing tools for the applications.

**Zero-downtime deployments.** Implemented zero-downtime deployment configuration on AWS ECS and configured Azure Kubernetes Service so client applications could be deployed with no downtime.

**Containers and Kubernetes.** Created Docker containers to keep applications consistent and portable across environments, and deployed Kubernetes on on-prem VM servers, including cluster upgrades.

**Security in the pipeline.** Added SAST, DAST and open-source scanning tools and integrated them into CI/CD.

**Operations.** Joined the on-call team that kept production healthy 24/7 for global availability. I took part in incident management, ran root cause analysis, prioritised incidents and service requests (sometimes leading the process with the Product Owner), and implemented permanent fixes to improve stability.

**Support and knowledge sharing.** Gave global development teams solution-design advice and diagnostics, helped with upgrades and patches, and prepared technical and functional documents for knowledge transition.
